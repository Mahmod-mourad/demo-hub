Project Management System — إدارة مشاريع Multi-tenant

      

        🚀 Live Demo
        GitHub Repo
      

    

    
بيحل مشكلة إيه؟ نظام SaaS لإدارة المشاريع بمعمارية Multi-tenant: كل شركة (Tenant) لها مستخدموها ومشاريعها ومهامها ومعزولة تماماً عن غيرها عبر RLS Policies — مع لوحة إحصائيات حية (Charts) وتحديثات Real-time عبر Socket.IO وإشعارات فورية.


    
📸 Screenshots — التطبيق شغّال (بحساب حقيقي)

    

      
      
      
      
    


    
🛠 Tech Stack

    

      Next.js 14NestJS
      Supabase (PostgreSQL + Auth)
      Multi-tenant + RLS Policies
      Socket.IO (Real-time)
      TypeScriptTailwind CSS
      JWT + BcryptSwagger API Docs
      Jest (Unit + Integration + E2E)
      Vercel
    


    
⚙️ How to Run

    
# 1) قاعدة البيانات المحلية (Supabase)
npx supabase start
# 2) السكيما والبيانات التجريبية — بالترتيب
psql "$DB_URL" -f scripts/01-tenants-and-plans.sql
psql "$DB_URL" -f scripts/02-profiles-projects-tasks.sql
psql "$DB_URL" -f scripts/03-notifications.sql
psql "$DB_URL" -f scripts/04-seed-demo-data.sql

# 3) الباك اند (NestJS على 3001) — بيتحط URL والـ Service Role Key بتوع Supabase
cd backend

        GitHub Repo
